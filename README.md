# Oficina-Robocode

Material de apoio para a oficina prática **Aprenda, Crie e Programa seu Próprio Agente Inteligente no Robocode**, desenvolvida para introduzir conceitos de agentes e estratégias de tomada de decisão por meio da programação de robôs.

## Sobre a oficina

A oficina utiliza o **Robocode** como ambiente prático para desenvolver agentes inteligentes que controlam tanques de guerra dentro de um jogo.

Durante a atividade, os participantes recebem códigos-base e ferramentas de apoio para criar, modificar e testar diferentes estratégias de comportamento para seus robôs.

A apresentação utilizada durante a aula está disponível em:

**`slides/`**

### `slides/`

Apresentação utilizada durante a aula com explicação.

### `codigos/`

Materiais utilizados na parte prática da oficina.

A pasta contém:

- códigos-base para os robôs;
- guia de funções e comandos;
- instruções para utilização e modificação dos robôs;
- demais arquivos necessários para os exercícios.

Os códigos foram desenvolvidos para servir como ponto de partida. A proposta é que os participantes possam modificá-los e experimentar diferentes comportamentos.

# Robocode

Esta oficina utiliza o **Robocode**, um ambiente de programação e simulação de batalhas entre robôs desenvolvido originalmente pela IBM e posteriormente mantido como projeto de código aberto.

- Projeto: https://github.com/robo-code/robocode
- Site oficial: https://robocode.sourceforge.io/
